## 展示代码

公开文件分为三类：

- 配对分析工具：为展示整理的可移植标准库实现，使用脱敏精简结果
- 状态复制增量：从最终 R7 的 observer 提取；保留原模块与发布源码 SHA，引用 SDK 定义采用原许可
- 神经模型与 schema：项目自有训练模块的当前快照；只提供合成输入 smoke，不包含老师、权重和原始轨迹

展示统计是已有实验的重算，整理过程中没有产生新的比赛收益证据。
