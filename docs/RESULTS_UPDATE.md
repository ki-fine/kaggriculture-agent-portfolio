## 记录官方依据

保存可以公开核对的榜单链接，或不含账号敏感信息的结果截图。记录查询日期、团队成绩、排名、总参赛队伍数和奖牌状态。

如果最终选择包含多个版本，需要分别说明，不能默认将团队最终成绩全部归因于 R7。百分位分母应使用最终榜单的同一口径。

## 更新展示材料

按以下顺序补充信息：

1. 在 `data/release_identity.json` 增加官方结果记录与来源
2. 更新 README 的项目状态和结果表
3. 在项目报告中增加“官方结果”小节
4. 更新简历条目

本地实验结果、旧版本标记和历史负结果继续保留。更新最终成绩不改变当时的样本限制。
